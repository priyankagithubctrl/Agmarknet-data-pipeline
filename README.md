# Agmarknet-data-pipeline
**Overview**

This project demonstrates an end-to-end Data Engineering pipeline built using Databricks, PySpark, Delta Lake, AWS S3 and AGMARKNET public APIs.
The pipeline ingests agricultural market data from AGMARKNET, processes it through Bronze, Silver and Gold layers using the Medallion Architecture, and produces analytical datasets for reporting and business insights.

**Data Sources**
AGMARKNET APIs
Daily Price & Arrival
MSP Transactions Above MSP
MSP Transactions Below MSP
Market Master
Commodity Master
